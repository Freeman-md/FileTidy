# 🗂️ FileTidy - Automated File Organizer

Tired of a cluttered **Downloads** folder? 

**FileTidy** automatically organizes your files into categories like **Images, Videos, Documents, Archives, and Code** – all with a single command! 🚀

## ✨ Features
✅ **Sorts files automatically** into categories  
✅ **Supports multiple directories** – Downloads, Documents, Desktop  
✅ **Works on Windows, macOS, and Linux**  
✅ **Real-time progress bar** for tracking large organizing tasks  
✅ **Simple CLI interface** (Work In Progress for Desktop Version)

## ⚙️ Installation & Usage
1. **Clone the repo**  
   ```sh
   git clone https://github.com/yourusername/FileTidy.git
   cd FileTidy
   ```

2. **Run the program**  
   ```sh
   dotnet run
   ```

3. **Enter the directory you want to organize**  
   ```sh
   Enter folder path(s) (comma-separated) or type 'exit' to quit:
   ```

   The tool will automatically organize and move files into categories.
